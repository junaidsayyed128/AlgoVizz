# AlgoVizz — Algorithm Visualization

AlgoVizz is a browser-based learning project that helps learners understand data-structure and algorithm concepts through graphical, step-by-step visualizations.

## Overview

The project uses JavaScript and D3.js to represent algorithm operations visually, making it easier to follow how values are compared, moved, searched, and arranged.

## Algorithms included

- Bubble Sort
- Insertion Sort
- Linear Search
- Binary Search

## Built with

- HTML
- CSS
- JavaScript
- D3.js

## Run locally

1. Clone or download this repository.
2. Open the `algorithm-visualizer` folder.
3. Open its HTML entry point in a web browser.

No backend service is required for the basic browser-based visualizer.

## Project goal

AlgoVizz is designed as an educational aid for exploring algorithm behavior and building intuition about common sorting and searching techniques.
